# iPhone Price Monitor Georgia

A price-monitoring tool for comparing iPhone prices in Georgia and keeping track of price changes over time.

## Features

* Search for iPhone models
* Compare prices from Georgian retailers
* Track price changes
* Find the best available prices
* Simple and fast interface

## Tech Stack

* Python
* JavaScript
* HTML
* CSS
* REST APIs
* Web scraping / data collection

## Goal

Make it easier to find and monitor iPhone prices in Georgia without manually checking multiple stores.
